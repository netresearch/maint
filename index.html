Data and provenance

Sources used

  • GitHub REST API — repositories, issues, pull requests, releases, contributors, commits
  • GitHub dependency graph — dependent repositories and packages
  • Packagist — download counts for published PHP packages
  • GitHub Container Registry — container pull counts

Coverage

Every non-archived repository in the organisation that the collector's configuration lists. Archived repositories are collected but excluded from the totals.

Historical coverage

Daily snapshots have been recorded since 31 May 2026.

Known gaps

  • Traffic figures (views and clones) need a token with repository scope. When that token is absent the fields are omitted rather than reported as zero.
  • Dependent counts come from GitHub's dependency graph, which only sees public repositories that declare the dependency. Treat them as a lower bound.
  • Container pull counts are collected on a best-effort basis and can be incomplete when a package is not linked to its repository.
  • Commit counts come from the commits API and are subject to its own limits on very large histories.

Methodology

What each figure means, and what it does not.

Cumulative or point-in-time?

Releases, downloads, commits, issues and pull requests are cumulative totals over the lifetime of each repository. Stars, forks, watchers and dependent counts are point-in-time values read at collection. Everything labelled "30 days" is a rolling window ending at the generation time — it is resampled on every run and is not a calendar month.

Not measured

  • Private repositories and internal forks.
  • Usage that leaves no public trace — vendored copies, mirrors, tarball installs.
  • Revenue, project value or customer impact. Nothing on this page is a business outcome.
  • Code quality. Activity is not a quality measure.

Estimated downstream reach

A single indicative number combining the signals that suggest a project is used and worked on beyond its own repository.

How it is calculated

External contributors × 3
Issues opened, open and closed × 1
Pull requests merged × 1
Forks × 2
Dependent repositories × 2

An estimate, not a reach or revenue figure. The weights are a judgement call, not a measurement, and the inputs carry the gaps listed above. Use it to sort, not to decide.
